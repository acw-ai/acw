# GETUS UC - Chrome Extension

Chrome Extension for automatic post-call disposition popups for 3CX V20.

## Features
- **No browser tab needed:** Agents don't need to keep `dispositions.getus.ca` open in a tab.
- **Background monitoring:** Runs quietly in the Chrome background.
- **Auto-popup on call end:** Automatically opens the small outcome window as soon as a 3CX call hangs up.
- **Desktop notifications:** Alerts the agent if they are in another application.
- **Auto-close:** The popup automatically closes itself as soon as the agent clicks "Save Outcome".

## How to Install in Chrome or Edge (30 Seconds)

1. Open Google Chrome (or Edge).
2. Go to `chrome://extensions/` (or `edge://extensions/`).
3. Turn on **Developer mode** toggle in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the `chrome-extension` folder: `D:\getus-dispositions\chrome-extension`.
6. Click the Extension puzzle icon in Chrome and **Pin** the GETUS icon to your toolbar.

## How to Use
1. Click the GETUS icon in your Chrome toolbar.
2. Sign in with your 3CX **Extension** and **PIN**.
3. That's it! When you take a call on 3CX and hang up, the popup opens automatically for you to choose the outcome.
