# ACW Agent Assist - Chrome Extension

Chrome Extension for automatic post-call disposition popups, after-call work notes, and queue management for business PBXs (including 3CX).

## Features
* **No browser tab needed:** Agents don't need to keep an active browser tab open.
* **Background monitoring:** Runs quietly in the Chrome background.
* **Auto-popup on call end:** Automatically opens the small outcome window as soon as a PBX call disconnects.
* **Desktop notifications:** Alerts the agent if they are focused in another application.
* **Auto-close:** The popup automatically closes as soon as the agent saves the disposition.

## How to Install in Chrome or Edge

1. Open Google Chrome (or Microsoft Edge).
2. Go to `chrome://extensions/` (or `edge://extensions/`).
3. Turn on **Developer mode** toggle in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the `chrome-extension` folder inside this repository.
6. Click the Extension puzzle icon in Chrome and **Pin** the ACW icon to your toolbar.

## How to Use
1. Click the ACW icon in your Chrome toolbar.
2. Sign in with your extension and PIN.
3. When you finish a call on your PBX and hang up, the wrap-up popup appears automatically.
